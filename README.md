# Codewars Solutions

Мои решения задач [Codewars](https://www.codewars.com) из профиля [erokha666](https://www.codewars.com/users/erokha666).

Решения организованы по рейтингу (`kyu`), затем по языку. Логика и отладочный вывод сохранены; форматирование части файлов нормализовано.

## Структура

```text
src/
└── tasks/
    ├── r5kyu/
    │   └── javascript/
    ├── r6kyu/
    │   └── javascript/
    ├── r7kyu/
    │   └── javascript/
    └── r8kyu/
        ├── csharp/
        └── javascript/
```

## Проверка

Требуется Node.js 18 или новее.

```bash
npm test
```

Команда проверяет синтаксис всех JavaScript-решений. C#-решение хранится как отдельный исходный файл без проекта и зависимостей.
